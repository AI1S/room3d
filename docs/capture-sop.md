# 拍摄 SOP（手机采集 → 高斯泼溅）

> 目标：一次拍成，重建不糊、不重影、方向不乱。**失败重拍的成本远高于多花 2 分钟。**

## 一、开拍前 60 秒检查

- [ ] 手机电量 > 30%，存储 > 5 GB，开飞行模式（避免来电中断）
- [ ] 1080p / 60fps；**不要用 0.5x 超广角**，用主摄 1x，全程不变焦
- [ ] 锁 AE / AF / 白平衡（部分机型需第三方相机 App）；关 HDR、关美颜、关防抖裁切
- [ ] 拉开窗帘但**避免逆光直拍窗户**；只开一盏主灯，别开彩色氛围灯
- [ ] 收拾场地：床帘拉开、桌面清空、地上不放杂物、**收走带屏幕/单据的私人物品**
- [ ] 画面里**不能有人**（室友要出镜或入画需先征得同意；公开前再自查一遍）

## 二、走位（2–3 分钟，像端着一杯水慢慢走）

1. **原地慢转 360°**（约 20 秒）：站房间中心，手机举到胸口高度，转的时候不要停、不要晃。
2. **沿中轴往返 2 遍**：从门口走到窗边再走回来，速度 ≤ 0.5 m/s，每走 3 步停 0.5 秒。
3. **补拍低处**：蹲下，镜头对着地面/床底边缘扫一遍（W5 会说"床底看不到"，这里能提高覆盖）。
4. **补拍高处**：举高，对着天花板和墙角扫一遍。
5. **回到起点，静止 3 秒**：闭合回路，后面 COLMAP / 位姿估计会感谢你。

**全程不要**：快速转身、边走边晃、突然变焦、进门出门、把手机贴到墙上。

## 三、拍完自查（30 秒）

- 回放：画面有没有大面积糊（走动太快）、有没有出现上一帧残影
- 有没有拍到人脸、门牌号、快递单、准考证、聊天屏幕
- 视频时长 2–3 分钟、体积通常 200–500 MB（1080p60）

## 四、抽帧（本仓库脚本）

```bash
py scripts/extract_frames.py --video D:/scan.mp4 --out data/scans/mine/frames --fps 2
```

- 默认 **2 fps**：2 分钟视频 ≈ 240 帧，够 splatfacto / COLMAP 用；
- 如果走动快、画面糊，改 `--fps 3`；如果帧太多跑不动，降到 `--fps 1`；
- 需要缩放到 1280 宽：加 `--width 1280`。

## 五、重建（本机 4090 Laptop 16 GB）

| 方案 | 装起来 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **Postshot**（Windows GUI） | 下载即用 | 最省事，直接导出 .ply/.splat | 商业化，免费版有水印限制 |
| Luma / KIRI 等在线 | 上传 | 零配置 | 免费额度有限，隐私要评估 |
| nerfstudio splatfacto | 需要 CUDA + tiny-cuda-nn | 完全可控，能改参数 | **Windows 编译 tiny-cuda-nn 很痛**，建议 WSL2 |

训练时长参考：80–120 ㎡ 三居 ≈ 20–40 分钟（L4/A10 级 GPU），本地 4090 Laptop 类似量级。

## 六、常见失败对照

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 重建出来糊成一团 | 走太快 / 光线太暗 / 大面积纯白墙无纹理 | 放慢 + 补光 + 对着有纹理的家具多停留 |
| 房间"躺平"或倒挂 | 数据集是 Z 轴朝上 | 页面点「修正朝向」 |
| 家具像被撕碎 | 遮挡太严重（走位没有绕开） | 绕家具半圈再走，别只从一个方向拍 |
| 窗户/镜子是黑洞 | 3DGS 对高光和镜面反射无能为力 | 记进"无法查看"，别硬补 |
| 尺寸差很多 | 3DGS 尺度不可观测 | 见下：放一个已知尺寸参照物 |

## 六点五、实测反例：一条"能拍但重建不出来"的视频

2026-11-23 拿一条真实宿舍视频（720×1280 竖屏，30fps，169s，36 MB）跑 COLMAP 4.2.1，**建图失败**。
留在这里当反例，拍之前对照一眼就知道哪些坑会直接让重建报废。

| 项目 | 实测值 | 结论 |
| --- | --- | --- |
| 2fps 抽帧 | 322 张（剔除室友出镜的 37–45 s） | 帧数够，但—— |
| 相邻帧重叠 | 24 帧间隔 0.5 s，**匹配中位数 0 inlier** | 0.5 s 转过的角度 > 手机水平视场（竖屏约 50°）⇒ 帧间无重叠 |
| 有效匹配对 | 2387 对里只有 607 对 > 50 inlier | 序列匹配基本失效 |
| mapper 结果 | 7 个碎片模型，每个只注册 2 张图（`Discarding reconstruction due to no initial pair`） | 位姿解不出来 |
| 拍摄距离 | 全程 0.2–0.5 m 特写（窗帘/空调/床架/柜子） | 没有整间房视角，即使解出来也只有表层碎片 |
| 运动模糊 | 梯度能量中位 8.26、p10 4.01；150–160 s 贴白墙处 sharp=0.7 | 有整段废帧 |
| 静止帧 | 相邻帧差 < 1.0 的占比 **0%** | 全程没停过，COLMAP 找不到可靠初始对 |

**致命组合 = 快速扫视 + 近距离特写 + 从不停顿。** 反过来说，只要做到：

- 单帧转过的角度 < 视场的一半（竖屏拍，约 25°/s 以内；横屏可以放宽到 35°/s）；
- 任何物体离镜头 ≥ 1 m，能看到"整面墙 + 地面 + 天花板"的关系；
- 每隔几秒有短暂停顿（0.5 s 就够），给特征匹配一个稳定的锚点；

COLMAP 才有可能解出尺度一致的位姿。**如果只想记一句话：慢到你觉得无聊为止。**

> 抽帧 fps 的选择也跟着变：正常慢走 2 fps 就够；如果手持较快，先抽 10 fps 跑一遍 SfM，
> 建图成功后再按 `--subsample-frames` 降采样给 3DGS 训练（详见 README 的重建章节）。

## 七、尺度校正（W3 才做，但拍摄时就要配合）

在房间里放一个**已知尺寸参照物**（A4 纸 297×210 mm，或标准门宽 0.9 m），
拍摄时让它出现在画面里至少 5 帧。W3 会用它把点云缩放到真实米制，
并输出一张「实测 vs 重建」误差表——这是评委最容易认可的自研技术点。
