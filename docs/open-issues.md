## P0 🔴 重建结果"雾 + 虚"（阻塞演示，也阻塞尺度校正）

### 现象

宿舍实拍（`data/VID_20261124_152501.mp4`，1920×1080 竖屏 4 分 12 秒）重建出的场景，在浏览器里近看是一片**半透明的烟/涂抹**，几何边缘虚，玻璃阳台门和窗户区域尤其糊成一团。截图见 `docs/screenshots/dorm-desktop.png`。

管线本身是通的：COLMAP 注册 1468/1514（97%），Brush 训练 7 分钟，转出 89.4 万点 / 14.5MB，页面渲染无报错。**问题只在观感**。

### 已排除的猜测（不要再重复这几条路）

| 猜测 | 怎么排除的 | 结论 |
| --- | --- | --- |
| 训练预算不够（步数/点数/SH 阶数少了） | 重训 30000 步 + 250 万点 + sh_degree=1（39MB spz），同机位 A/B 对比 | **不是瓶颈**。细节略实，但雾几乎没变，体积涨 2.7 倍 |
| 相机没到过的地方在"猜" | 把 89.4 万颗高斯投影到全部 1468 个相机做可见性统计 | **0.0% 的高斯被 0 个相机看到**；可见数中位 169，最少 18 |
| 近透明小点堆成的雾 | `splat-transform -V "opacity,gt,0.05"` 丢掉 23% 最透明点后渲染 | **看不出变化**，雾不是透明度问题 |
| 自动 filter floaters | `splat-transform -F`（默认 0.05,0.1,0.004） | 215 万点里只删 2.0%，效果有限 |
| 默认机位不好 | 试了「房间中心」机位 | **更乱**。近场几何本身就糊，不是机位问题 |
| 前端渲染器设置 | 换 PLY / 换 spz / 换 sh 阶数，同机位比对 | 渲染链路一致，问题在数据不在渲染 |

### 真因（当前判断）

**几何在"深度方向"没有被约束住。** 3DGS 在一条视线上靠视差定深度；这条视频 1514 帧几乎走同一条手持轨迹、同一水平高度、转角又快，导致大部分表面**只有一个方向的视差**。优化器于是用两种东西凑颜色：

- 各向异性 ~12:1 的**细长针状高斯**（画面上的"条纹/拉丝"）
- 覆盖一大片的**半透明大斑**（画面上的"烟"）

再加两个场景因素：玻璃阳台门/窗是透明+高反射，3DGS 没有"透明面"概念，只能把反射当表面糊上去；衣物、床帘挡住墙面，遮挡区只有掠射视角。

**拍摄侧和算法侧各占一半**，但性质不同：拍摄只能下次改，算法侧现在还能从后处理抠回一部分。

### 候选方案（按性价比排序，都还没做）

1. **深度一致性剪枝**（最值得做）
   用 COLMAP 稀疏点云当几何锚（33 万点，平均重投影误差 1.30px）。把每颗高斯投影到最近相机，比较它和附近稀疏点的深度；偏差超过 3× 局部点间距就删除或收缩。
   → 直接针对"没被深度约束住的补丁"，理论依据最干净。

2. **尺度 / 各向异性上限**
   最长轴 > 5cm 的截断；长宽比 > 30:1 的针状高斯直接删。画面上的"拉丝"主要来自它们。

3. **透明度重标定**（渲染层，零风险）
   `α' = α^γ`（γ≈1.5），压掉半透明的雾感。可以先在页面里当参数试，效果好再写进管线。

4. **重训加正则 / 换后端**
   Brush 的 `--scale-loss-weight`、`--opac-loss-weight`；或换 splatfacto（带 MCMC 抖动 + 周期性 opacity reset，天生更少 floater）。代价是一次重训 7–15 分钟 + 需要搭 nerfstudio 环境。

5. **换场景按 SOP 重拍**（见 P2）
   多角度视差、走位中停顿、避开玻璃。这条和 1–4 不冲突，最终都要做。

### 必须补的：客观评测

目前所有判断都是"看截图"。要做的是用 COLMAP 位姿把渲染图和原视频帧对齐，算 **PSNR / SSIM**。有了这个数，才能说某个方案"真的处理掉了噪点"，而不是"好像好点"。这个也是答辩里能拿出来的指标。
