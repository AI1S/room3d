# Roadmap · 8 周（每周 10–15 小时）

> 原则：每周结束时必须有一件**能拿给人看**的东西。做不完就砍功能，不砍验收标准。

## W1 · 最小闭环（本周）

**做**：网页能载入 .splat、能转、能显示房源信息、能回答 4 个问题（含拒答）；本地拖拽文件。

**验收**：
- [x] `npm run dev` 打开能在 3 秒内看到房间
- [x] 手机宽度 390px 下布局不塌、能转动
- [x] 问"衣柜内部能看到吗"→ 回答"没有采集到，无法查看"（不脑补）
- [x] 换一个 .splat 文件（拖拽 / 上传按钮）能正常显示

**产出**：这个仓库 + 两张截图。

## W2 · 一键管线（已完成）

**做**：把「视频 → 抽帧 → 重建 → 放进 scans/ 」串成一条命令；网页顶栏能切换房源（读 `scans/index.json`）。

**验收**：
- [x] `py scripts/pipeline.py --splat scene.ply --id dorm --title 宿舍` 跑完，`public/scans/` 里出现新目录 + `index.json` 自动更新
- [x] 刷新网页，顶栏「房源下拉」多出这套，点开就是新房间（`#/scan/<id>` 可直接分享）
- [x] 3DGS PLY → .splat 转换有逐字节单测 + 渲染往返对比（28079 点往返 pos maxerr 0 / rgba 完全一致）
- [x] `npm run build` 产物含 `scans/index.json`、`_headers`，preview 下 200，控制台零报错
- [x] 仓库里留了一套 `scans/selftest`（28079 点的往返自测场景），用来在没 GPU 时也能演示"房源切换"

重建环节保持手动（`--splat` 传 Postshot 导出结果），**不要为了自动化去啃 tiny-cuda-nn**。
没装 ffmpeg 时管线会打印 `winget install Gyan.FFmpeg` 然后停在第 1 步，不会假装成功。

## W3 · 尺度校正 + 2D 户型图

**做**：A4 / 门宽参照 → 点云估计地面墙面 → 米制尺度 → 俯视投影生成 2D 户型 SVG。

**验收**：主尺寸误差 ≤ 2 cm（对比卷尺实测 5 个尺寸），输出误差表。← **这是核心自研点 1**

## W4 · VLM 出结构化 JSON

**做**：抽 8–12 张关键帧 → VLM（Qwen-VL）→ schema 校验 → 生成 `meta.json`（房间、家具、门窗、朝向）。

**验收**：20 个房间字段准确率 ≥ 80%；schema 校验拦住所有格式错误；输出一张混淆表。
← **核心自研点 2**

## W5 · 严格 grounding 问答

**做**：把 W1 的规则替身换成 LLM（Qwen-7B API），prompt 里只给 JSON，强制"没有就说没有"。

**验收**：30 题评测集，「无法查看」命中率 ≥ 90%，编造率 = 0（人工判定）。
**顺序不能变**：先判"不能答"，再判"能答"——W1 的 `answer()` 已经把这个顺序定好了。
← **核心自研点 3（幻觉率评测）**

## W6 · 一个亮点（三选一）

1. **拍摄引导**：纯前端规则（拉普拉斯方差判模糊 / 陀螺仪角速度 / 位姿覆盖热力图），拍的时候实时提示"太快了""这块还没拍到"。
2. **采光推算**：窗口位置 + 朝向 + 层高 → 一天中光照进深变化（几何推算，标明"不是实测"）。
3. **看房决策卡**：把"能放多大的床""柜子够不够""采光几小时"变成一页可分享的卡片。

建议选 1（最容易演示出效果，也最难被说"只是调 API"）。

## W7 · 演示与材料

演示视频 2–3 分钟（拍真实空房间，不要用宿舍）、PPT 10 页、README + 架构图。
主线叙事：**"我们不在尺寸上撒谎"**（3DGS 尺度不可观测 → 参照物校正 → 误差表 → 拒答未采集区域）。

## W8 · 兜底

断网版录屏、SuperSplat 导出的独立 HTML 备份、答辩 Q&A 准备（见下）。

## 答辩预设问题

| 评委可能问 | 准备怎么答 |
| --- | --- |
| 高斯泼溅能测尺寸吗？ | 不能，它是 view synthesis，尺度不可观测。所以我们加参照物校正 + 误差表，对外只说"尺寸参考"。 |
| 和如视/贝壳比呢？ | 他们用激光点云（≤10 mm），我们只有手机，定位是"低成本、可自我核验"，不拼精度。 |
| 大模型会不会编？ | 有拒答分支 + 30 题评测集，编造率当指标量化。 |
| 商业价值？ | 不主攻商业赛道；价值在"让没有专业设备的中小中介也能出可看房的链接"。 |

## 明确不做（写进 PPT 反而加分）

微信小程序、原生 App、端侧离线模型、多用户/登录/支付、多房源后台、实时多人看房、自研渲染器。
